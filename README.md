# Finance Chat

Aplicacao local para organizar financas pessoais por conversa.

## Recursos

- Registro de despesas pelo chat.
- Cadastro de renda mensal, semanal ou quinzenal com duas datas e dois valores.
- Resumo por competencia mensal.
- Dashboard com saldo, gastos por categoria, evolucao e projecoes.
- Exportacao em CSV ou TXT.
- Assistente local, sem dependencia de API externa para conversar.

## Desenvolvimento

```sh
npm install --package-lock=false
npm run dev
```

Depois abra a URL exibida no terminal.

## Build

```sh
npm run build
```
